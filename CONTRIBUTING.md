# Contributing to Luminar Calculator

Thank you for your interest in contributing to **Luminar Calculator**! We strive to combine open-source transparency with Apple-level polish, Nothing OS simplicity, and Linear precision.

## Design & Code Philosophy
1. **Jetpack Compose Only:** All UI developments must use Jetpack Compose following strict MVVM architecture.
2. **Animations:** Keep animations smooth, fast, and meaningful. Use physics-based spring animations where appropriate. Avoid unnecessary layout shifts.
3. **Typography & Minimal Cognitive Load:** Maintain clean spacing, clear typographic hierarchy, and one-hand usability.
4. **Brand Protection:** Forks and community contributions are welcome, but the **Luminar Calculator** name, logo, and official visual identity remain proprietary to official releases.
